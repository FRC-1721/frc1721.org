Robots Shouldn't Quit But Yours Did!

Theres a problem reaching the server, suggested steps for repair are below!

Troubleshooting Checklist

  • Ensure the server has power and is turned on.
  • Check the network is up.
  • Verify the server's status lights are active.
  • Make sure the network switch lights are on
  • Attempt to reboot the server if safe to do so. (Please have a code student safely power off and on the server)
